# Five-minute walkthrough

Start with the failure mode: financial forecasts are easy to overstate through data leakage and unrepeatable data. Show validation at ingestion, chronological splits and lag-only features. Explain validation-only ridge selection and the explicit prior-close field that fixed the first held-out directional calculation. Open a prediction ledger, a backtest ledger, and `manifest.json` to demonstrate independent auditability. Close with limitations: public data revisions, unadjusted corporate actions, and illustrative—not deployable—strategy performance.
